# Hermit Sustainability Advisory — Executive PMO Portal

An interactive, browser-based Project Management Office (PMO) dashboard designed for **Hermit Advisory**. It tracks clean-energy, storage, policy compacts, and capital mobilization mandates across Zimbabwe and the Southern African region.

## 🚀 Key Features

* **Portfolio Executive Overview:** Live KPI metrics, aggregate completion indices, and sector breakdown.
* **Interactive Projects Register:** Searchable and filterable directory of all 12 project mandates.
* **Granular Task & Deliverables Ledger:**
  * **Live Progress Sliders (0–100%)**: Drag to update task progress with real-time recalculation of overall project completion.
  * **Status Dropdowns**: Toggle between *Complete*, *In Progress*, *Needs Review*, *Overdue*, *On Hold*, and *Not Started*.
* **Critical Path & Risk Surveillance:** Automated flagging of high-priority bottlenecks (e.g. Kariba BFS & Financial Close, Rudra NDA countersignature, BESS staffing).
* **Multi-Year Roadmap / Gantt:** Delivery schedule visualization spanning 2025–2030 programmatic horizons.
* **Capital Mobilization Tracker:** Pipeline tracking for banking facilities and strategic joint ventures (Stanbic, EcoBank, NBS, Rudra Enterprise, Oyu Green).
* **Persistence & Export:**
  * Auto-saves changes directly to browser `localStorage`.
  * **Export to CSV / Excel** and **Executive Print / PDF** support.

## 💻 Getting Started

Simply open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox). No build step, database setup, or server installation is required.
